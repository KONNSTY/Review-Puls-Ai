# Trial and conversion metrics

- Activation: installed → onboarding complete → first demo reply → first real review imported.
- Value: time to first approved reply, percentage of pending reviews cleared, publish confirmation rate.
- Safety: escalation rate, unsafe-output rejection rate, auto-publish rollback rate.
- Revenue: trial-to-paid, Starter/Growth mix, MRR, logo churn, gross AI cost per generated reply.
