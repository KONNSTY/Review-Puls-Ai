# Platform compatibility (checked 2026-09-12)

| Platform          | Decision                                                                                                                                                                                               | Official source                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| Shopify app stack | React Router template is the recommended new-app path; template is checked into this repository                                                                                                        | https://shopify.dev/docs/apps/build/scaffold-app                      |
| Shopify API       | Target `2026-07`, the latest stable version on the check date; update quarterly                                                                                                                        | https://shopify.dev/docs/api/usage/versioning                         |
| Shopify privacy   | `customers/data_request`, `customers/redact`, and `shop/redact` are mandatory; requests must receive a 200-series response and complete within 30 days, with shop redact sent 48 hours after uninstall | https://shopify.dev/docs/apps/build/compliance/privacy-law-compliance |
| Shopify billing   | New public apps should use Shopify App Pricing configured in Partner Dashboard; do not create a parallel Stripe subscription                                                                           | https://shopify.dev/docs/apps/launch/billing/shopify-app-pricing      |
| OpenAI            | Use strict `json_schema` structured output where supported; model is server-configurable and defaults to `gpt-4o-mini`                                                                                 | https://platform.openai.com/docs/api-reference/responses-streaming    |
| Supabase          | Use a shared transaction pooler for serverless access, SSL, and small application pool; migrations are versioned in `supabase/migrations`                                                              | https://supabase.com/docs/guides/database/connecting-to-postgres      |
| Review providers  | No live capability is claimed until current official provider docs and credentials are verified; adapters are intentionally unsupported-safe                                                           | provider contracts are an external launch gate                        |
